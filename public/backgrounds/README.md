# Background Images

The app currently uses this default global background image:

```txt
public/backgrounds/sverige.webp
```

The matches, individual match, and bracket pages currently use:

```txt
public/backgrounds/Gyökeres.jpeg
```

Replace those files to change the relevant backgrounds.

Recommended source image:

- wide image, at least 1920px wide
- dark or medium contrast
- JPG, PNG, WebP, or SVG
- keep important details away from the center, because cards and content sit there

If you use another filename or extension, update `.app-background-image` in `app/globals.css`.
